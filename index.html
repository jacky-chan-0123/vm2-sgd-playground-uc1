01 / Interactive framing

改一個因素，看一次差別。

以下是概念模擬，不是相機成像預測。真正的效果，要用自己的手機實測。

建築 / 正面對稱
教學插畫 · 非實拍

建築以你提供的滙豐總部教材為靈感，並非精確建築模型。光線、曝光與透視採簡化呈現；畫面不包含實際手機的感光元件、HDR 或鏡頭差異。

先站好，再調相機。

正面拍平衡、轉角拍體積、局部拍材質。同一棟建築，可以講三個故事。

先用 1×；拍不下先安全退後。點按建築後稍降曝光，但不要壓黑全部。少量後製可能改善透視，卻不能保證救回已失去的亮部細節。
02 / Five-minute speech

五分鐘，把取景說清楚。

以預先拍好的比較照片或本站示意演講。現場拍攝與討論請另預留 10–15 分鐘。

REHEARSAL TIMER總長 5 分鐘
00:00 / 05:00
準備好，從觀察開始。

每段時間包含短暫展示圖片與觀察。請先排練，依自己的語速調整停頓；計時器不會自動朗讀。

00:00–00:35開場｜拍照不是把所有線拉直

大家好！今天我們用手機拍三種主題：建築、山和大樹。以香港滙豐總部的鋼構，以及流水響風格的山林作例子。先記一個口訣：一倍、退後、拿直、稍降曝光。拿直，是避免手機不小心歪斜；不是要把所有山坡和樹幹都拉直。今天的網站圖片是教學示意；真正的實測，要看我們現場拍出的比較照片。

展示提示｜展示建築、山林示意。說明：沒有實拍照片時，不把示意稱為實測成果。
00:35–01:40站位與角度｜先用 1×，先退後

先看建築。通常先用一倍主鏡頭，畫質和觀感比較穩妥。拍不完整，先確認背後安全，再退遠，不急著切零點五倍。超廣角在狹窄街道很有用，但重要柱子別放在最邊緣，避免拉伸。第一組實測，我們站在同一位置，用一倍拍 A：手機明顯向上仰。再拍 B：降低仰角，看看兩側直線是否仍向上匯聚。這一步只測角度，不要求兩張都拍完整。若要改善完整度，再安全退後，拍第三張。左右歪斜可以靠格線與水平儀檢查；上窄下寬則是仰拍透視，兩者不是一回事。拍不下時，也可在安全位置提高機位，或橫拍保留環境，不必冒險追求全棟。

展示提示｜展示仰拍 A / B，先比較牆角的匯聚，再展示安全退後的完整取景。預留短暫觀察時間。
01:40–02:35光線與曝光｜保住亮部，不壓黑全部

第二組實測是曝光。固定站位與一倍鏡頭，點按建築對焦，先用相機自動曝光拍 A，再稍微降低曝光拍 B。放大看白色鋼構、天空和玻璃：B 有沒有保住更多亮部層次？暗處是否又太黑？不要只因為照片變暗，就說它更好。清晨、傍晚的側光能帶出鋼構立體感；陰天適合看外牆色彩與細節。日落後，天空仍藍時，建築燈光與天空較容易平衡。光線不足就雙手握穩，找安全支撐，開夜景模式後等它拍完再移動。不同時段比較，會受天氣與亮燈安排影響，不能當成只改一個因素的嚴格測試。

展示提示｜展示曝光 A / B，指向同一處亮部與陰影。四種光線圖片若是模擬，要明確標示。
02:35–03:30三種拍法與修正｜同一棟，三個故事

第三個練習，是同一棟建築拍三張。第一張正面對稱，在安全位置對準中央，讓入口與窗格左右平衡。第二張轉角立體，從斜向位置讓兩面外牆入鏡。第三張局部細節，只拍鋼構、玻璃接點或光影，不必每次拍全棟。有真正的長焦鏡頭，可以試拍窗格；少用手指放大，數碼放大不等於更多細節。拍完只做少量修正：拉直、適度校正垂直透視、降低亮部、稍提陰影，再裁掉邊緣雜物。實測時保留原圖，另存修正版，比較柱子是否更端正，也檢查頂部是否被裁掉。現場四周留一點空間，因為透視校正會犧牲部分畫面；已經過曝成純白的地方，也未必救得回來。

展示提示｜展示正面、轉角、細節三張；再展示一組原圖與修正版，圈出裁切損失。
03:30–04:30山與大樹｜保留自然的方向

最後看山和大樹。山脊有起伏，不能當水平線；湖岸線也未必水平。有遠方海平線可以參考，沒有就先用手機水平儀。第四組實測，拍 A：水平儀歸零，保留左低右高的山坡。再把 A 複製一份，旋轉成 B，硬把某一段山脊拉平，看看其他景物是否反而變歪。樹也可能自然傾斜，拍森林要看整體，不只看一棵。拍整棵樹，安全退遠、減少仰角；刻意仰拍時，枝幹向上匯聚很正常。超廣角把重要樹幹放近中央。湖邊可保留樹與倒影；小徑能引導視線；逆光葉片則先找簡潔背景，再試曝光。不摘葉，不踩樹根。拍不完整，也可以只拍樹皮、枝葉或一座山峰。

展示提示｜切換山景 A / B，辨認自然坡度。展示整棵樹、仰拍與倒影示意；不把傾斜樹幹當校正基準。
04:30–05:00結語｜用比較取代猜測

今天的重點，是每次先拍一張，再只改一個因素，看差別出在哪裡。比較清晰度、亮部細節、線條方向和畫面完整度，而不是一律選更暗、更直的照片。最後一起記：一倍、退後、拿直、稍降曝光。山保留坡度，樹保留姿態；水平儀用來校正手機，不是把大自然全部拉直。先照顧安全與環境，再帶走一張有想法的照片。謝謝大家！

展示提示｜帶觀眾重複口訣。五分鐘到，實地練習另行開始。
03 / Field experiments

不要只說「比較好」，拍下證據。

以下是可執行的實測例子，不是已完成的測試報告。每次盡量只改一項條件，保留原圖。

TEST / 01

仰拍角度

準備：同一安全站位、1×，選牆角清楚的建築。

操作：A：明顯仰拍。B：降低仰角，其他條件盡量不變。另拍 C：安全退後，嘗試完整取景。

觀察：A / B 看垂直線匯聚；B / C 看完整度。退後與角度的影響分開記錄。

TEST / 02

亮部與曝光

準備：固定站位、鏡頭與構圖；若支援，鎖定對焦，避免光線快速改變。

操作：A：自動曝光。B：適度降低曝光。保留未編輯原圖，不套濾鏡。

觀察：放大天空、白色外牆及陰影。亮部更完整但陰影過黑，不一定是改善。

TEST / 03

同棟三種構圖

準備：以滙豐總部或另一棟可安全拍攝的建築為主題。

操作：用 1× 分別拍正面、轉角及細節。拍細節可以走近；有真長焦也可另做測試。

觀察：哪張表現秩序、哪張表現體積、哪張表現材質？這是創作比較，沒有唯一勝者。

TEST / 04

山脊不是水平線

準備：選一段自然左低右高的山坡；先用手機水平儀。

操作：A：保持手機水平拍攝。複製 A，旋轉成 B，刻意把選定山脊線段拉平。

觀察：比較整體方向與旋轉裁切。注意山脊不是校正基準；這組示範測的是旋轉處理。

TEST / 05

自然樹姿與仰拍

準備：選一棵自然傾斜的大樹，留在步道，確認可安全取景。

操作：先用水平儀拍整樹 A；複製並強行旋直樹幹成 B。另拍向上取景 C，觀察匯聚。

觀察：A / B 看樹姿是否被誤判。C 看透視與氣勢，不把刻意仰拍視作拍攝失誤。

TEST / 06

少量後製

準備：挑一張四周有留空間的建築原圖，另存編輯版本。

操作：先只校正透視，記錄裁切。再另存一版調亮部與陰影，最後才裁雜物。

觀察：逐步比較線條、天空與噪點。亮部已截斷或陰影噪點太多時，調整未必能挽救。

站位比照片更重要。

拍滙豐總部時，選合法、安全且不阻路的公共位置；不要為了正面對稱站上車道。退後前先看路況，不攀爬、不進入受限制區域。人物入鏡時，尊重私隱，避免公開可辨識的陌生人特寫。

森林不是攝影佈景。

在流水響風格的山林練習時，留在開放步道，不踏樹根、不摘葉、不涉水追倒影。靠安全支撐穩定手機，不為仰拍走入危險位置。出發前另查天氣、開放及交通資訊。
